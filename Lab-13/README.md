# Assignment 13: Reduce, Some, Every and Map

## Aim
To use reduce, some, every and map methods on arrays while keeping the original array unchanged.

## Task 1: Reduce Method

Created an array containing prices 120, 45 and 300.

Used reduce() with an initial value of 0 to calculate the total price.

Output:
Total Price: 465

## Task 2: Some and Every Methods

Created an array containing marks 72, 85, 30 and 90.

- some() checks whether any mark is below 40.
- every() checks whether all marks are 35 or more.

Output:
Any mark below 40: true
All marks are 35 or more: false

## Task 3: Map Method

Created an array containing marks 72, 85, 64 and 90.

Used map() to create a new array by adding 5 to every mark. The original array remains unchanged.

Output:
New Marks: [ 77, 90, 69, 95 ]
Original Marks: [ 72, 85, 64, 90 ]
