Assignment 4: JavaScript Functions

Aim:
To write a function with a return value, an arrow function, and a default parameter.

Task 1: Function with Return Value
Created a function named greet that takes a name and returns a greeting message.

Output:
Hello, Asha

Task 2: Arrow Function
Created an arrow function named square that returns the square of a number.

Output:
36

Task 3: Function with Default Parameter
Created a function named billWithTax that calculates the bill amount with tax. The default tax rate is 0.18.

Output:
118
