# Assignment 10: Objects and Destructuring

## Aim
To create an object, read and change its properties, and extract values from an array and an object using destructuring.

## Task 1: Student Object

Created a student object with name, roll and marks properties.

Changed the marks from 78 to 81 and printed the updated marks.

Output:
Rohan
81

## Task 2: Array Destructuring

Created an array containing Maths, Science and English.

Used array destructuring to store the first two subjects in the variables first and second.

Output:
Maths
Science

## Task 3: Object Destructuring

Created a student object with name, roll and marks properties.

Used object destructuring to extract name and roll.

Output:
Rohan
12
