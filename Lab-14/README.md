# Assignment 14: Timers and Intervals

## Aim
To run code after a delay using setTimeout(), cancel a timer using clearTimeout(), and repeat code using setInterval().

## Task 1: setTimeout()

Created a program that prints Start, schedules Timer done with a delay of 0 milliseconds, and then prints End.

The timer callback runs after the synchronous code finishes.

Output:
Start
End
Timer done

## Task 2: clearTimeout()

Created a timer that schedules the message Not shown after 1000 milliseconds.

Stored the timer ID in a variable and cancelled it using clearTimeout().

Output:
Cancelled

## Task 3: setInterval() and clearInterval()

Created a program that prints Tick with a count every 200 milliseconds.

The interval stops when the count reaches 3.

Output:
Tick 1
Tick 2
Tick 3
