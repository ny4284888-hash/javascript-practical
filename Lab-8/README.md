Assignment 8: Inheritance, Methods and Composition

Aim:
To understand inheritance, methods and composition in JavaScript.

Task 1: Inheritance

Inheritance allows one class to use the properties and methods of another class.

Person is the parent class.
Teacher is the child class that extends Person.
The super() method calls the parent class constructor.

Output:
Hi, I am Anita

Task 2: Locker Class

A class can contain methods to perform specific tasks.

The Locker class stores a PIN.
The checkPin() method checks whether the entered PIN matches the stored PIN.
It returns true if the PIN matches and false otherwise.

Output:
false
true

Task 3: Composition

Composition means using an object of one class inside another class.

The Engine class stores the power of the engine.
The Car class contains an Engine object.
The start() method displays the engine power.

Output:
Car starts with 150 HP
