# Assignment 9: DOM, Validation, Storage and Quiz

## Aim
To change a webpage using a click, validate form values, save text in local storage, and create a simple quiz using JavaScript.

## Task 1: DOM Manipulation
Created a webpage with a Welcome heading and a Change text button.

When the button is clicked, the heading changes to Button clicked.

Output:
Button clicked

## Task 2: Form Validation
Created a function validateForm(name) that checks whether the name is empty.

If the name is empty, it returns the error message Name is required.

Output:
[]
["Name is required"]

## Task 3: Local Storage
Created a webpage with a text box and Save button.

The entered text is stored in localStorage using the key note. The saved text appears when the page is reopened.

## Task 4: JavaScript Quiz
Created a quiz with the question What is 2 + 3? and three options: 4, 5 and 6.

If the user selects 5, the page displays Correct. Otherwise, it displays Try again.
