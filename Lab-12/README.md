# Assignment 12: Callbacks and Higher-Order Functions

## Aim
To pass a function as an argument to another function and call it.

## Task 1: applyTwice and addTen

Created a function applyTwice() that takes another function and a value as arguments. It calls the given function twice on the value.

The addTen() function adds 10 to a number.

Output:
25

## Task 2: formatMarks and Callback

Created a function formatMarks() that accepts marks and a callback function.

The arrow function formats the marks into a message.

Output:
Marks: 76/100

## Task 3: repeatAction and Callback

Created a function repeatAction() that calls an action for each round.

The arrow function prints the round number.

Output:
Round 1
Round 2
Round 3
